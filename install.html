⬇ Download Luma Android TV APK

The link above goes directly to a GitHub Release APK. If Downloader opens this page instead of downloading, select the large Download APK link.

  1. On Shield, open Downloader and enter this installation page URL (not the main Luma website).
  2. Select Download Luma Android TV APK, then approve the Android package installer.
  3. Launch Luma from the Shield's Apps screen, not from Downloader's web browser.
  4. Open Live TV → Connections and enter your IPTV provider inside the installed app.

Web updates: Luma refreshes the published website when the installed APK starts. Native Android/player updates require a signed APK install, and may require uninstalling this debug-signed preview first. Export your Luma settings before uninstalling.
