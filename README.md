# Luma Media Center

A free-start responsive media center web prototype intended for Safari, Android browsers and desktop. Cinematic UI with fictional sample entries, local watchlist/progress, personal HTTPS video URL playback, and settings.

## Publish with GitHub Pages

In this repository open Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch: **main**, folder **/(root)** → Save. Once deployment succeeds, visit https://cj42izzle.github.io/Luma-Media-Center/ in Safari. Use Share → Add to Home Screen.

## Important limitations

Fictional demo titles are not real streaming content. Trakt, Simkl, iCloud, TMDB, and cross-device sync are **not connected**. Playback depends on the user's authorized video URL and Safari codec/host compatibility. Data stays in the browser via localStorage (export a backup from Settings). This is not a native tvOS app; Apple TV requires a separate native client. Never commit credentials or API secrets to this public repository.
